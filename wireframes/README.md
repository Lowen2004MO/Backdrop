# UI wireframes

Open `index.html` to browse all 20 wireframes. Each SVG can also be opened separately or printed. Black outlines, white backgrounds and short labels only.

Based on the application templates. Repeated records share a detail wireframe; uploaded question and survey layouts have separate variants. Conditional results are shown within their page. Framework administration, redirects, downloads and action-only endpoints are outside this set.
